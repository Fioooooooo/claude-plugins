# Code Review Plugin

一个专业的 Claude Code 代码审查插件，帮助你对最近的代码变更进行全面、深入的审查。

## 功能特性

- 🔍 自动分析最近的 Git 变更
- 📊 多维度代码质量评估
- 🔒 安全漏洞识别
- ⚡ 性能瓶颈检测
- ✅ 测试覆盖率评估
- 📝 文档完整性检查

## 使用方法

在 Claude Code 中运行以下命令：

```bash
/code-review
```

插件会自动获取以下信息进行审查：
- 当前 Git 状态
- 最近一次提交的变更（`git diff HEAD~1`）
- 最近 5 次提交记录
- 当前所在分支

## 审查维度

### 1. 代码质量
- 代码可读性和清晰度
- 代码结构和组织
- 最佳实践的遵循情况
- 代码复杂度评估

### 2. 安全性
- 潜在的安全漏洞
- 敏感信息泄露风险
- 输入验证和数据处理
- 权限和访问控制

### 3. 性能
- 算法效率分析
- 潜在的性能瓶颈
- 资源使用优化建议
- 数据库查询优化

### 4. 测试
- 测试覆盖率评估
- 测试用例质量
- 边界条件处理
- 错误处理机制

### 5. 文档
- 代码注释完整性
- 函数和类文档
- 复杂逻辑说明
- API 文档更新

## 输出内容

审查报告将提供：
- ✨ 具体且可操作的改进建议
- 📍 必要时的逐行代码注释
- ⚠️ 优先级标注的问题清单
- 💡 最佳实践推荐

## 权限说明

此插件仅使用以下 Git 命令：
- `git status` - 查看工作区状态
- `git diff` - 查看代码变更
- `git log` - 查看提交历史
- `git branch` - 查看当前分支

所有命令均为只读操作，不会修改您的代码或 Git 历史。
