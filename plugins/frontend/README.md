# Frontend 插件

前端开发通用助手插件，提供跨框架的组件设计模式、性能优化、测试策略、无障碍设计等通用技能。

## 定位

本插件专注于**框架无关的前端通用技能**，适用于所有前端开发场景。如果你需要特定框架的支持，请安装对应的框架插件：

- **Vue 开发**：安装 `vue` 插件
- **React 开发**：安装 `react` 插件
- **Angular 开发**：安装 `angular` 插件（计划中）

## 功能

本插件提供以下通用前端开发能力：

- **组件设计模式**：跨框架的组件设计最佳实践
- **性能优化**：代码分割、懒加载、性能分析等通用优化策略
- **测试策略**：单元测试、集成测试、E2E 测试的通用方法
- **无障碍设计**：WCAG 标准、语义化 HTML、键盘导航等
- **状态管理概念**：状态管理的通用模式和最佳实践
- **工程化配置**：构建工具、代码规范、CI/CD 等
- **代码质量**：代码审查、重构、架构设计等
