# Nuxt 插件

Nuxt.js 开发助手插件，提供 Nuxt 模块、Nuxt UI、Motion 动画等 Nuxt 专属技能。

## 功能

本插件包含以下 skills：

- `nuxt-modules` - Nuxt 模块开发和集成
- `nuxt-ui` - Nuxt UI 组件库使用和定制
- `nuxt` - Nuxt 核心功能和最佳实践
- `motion` - Motion 动画库集成

## 使用方法

### Skills

使用 `/` 命令调用相应的 skill：

- `/nuxt:nuxt-modules` - 获取 Nuxt 模块相关的帮助
- `/nuxt:nuxt-ui` - 获取 Nuxt UI 组件库相关的帮助
- `/nuxt:nuxt` - 获取 Nuxt 核心功能相关的帮助
- `/nuxt:motion` - 获取 Motion 动画相关的帮助
