# Vue 插件

Vue.js 开发助手插件，提供 Composition API、Vue Router、Pinia 状态管理、组件开发等 Vue 专属技能。

## 定位

本插件专注于 **Vue.js 框架特定的开发技能**，包括 Vue 3 的最新特性和最佳实践。

如果你需要跨框架的通用前端技能（如性能优化、测试策略、无障碍设计等），请同时安装 `frontend` 插件。

## 功能

本插件提供以下 Vue 专属开发能力：

- **Composition API**：组合式 API 的使用模式和最佳实践
- **Pinia 状态管理**：状态管理的现代化方案
- **组件开发**：Vue 组件的设计、开发和优化
- **响应式系统**：深入理解 Vue 的响应式原理
- **生命周期**：组件生命周期的使用和优化
- **指令和插件**：自定义指令和插件开发
- **TypeScript 集成**：Vue 与 TypeScript 的最佳实践
- **Vite 构建**：基于 Vite 的项目配置和优化
