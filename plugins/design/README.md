# Design 插件

Design 插件是一个综合设计辅助工具集，未来将集成设计系统生成、组件库推荐、响应式设计助手、设计审查等更多功能，为开发者和设计师提供全方位的设计决策支持。

## 功能特性

### ui-ux 设计资源数据库

> 来源: https://github.com/nextlevelbuilder/ui-ux-pro-max-skill

一个可搜索的 UI/UX 设计资源数据库，包含 UI 风格、配色方案、字体组合、图表类型、产品推荐、UX 指南以及特定技术栈的最佳实践。

核心功能：

- 57 种界面风格，玻璃形态、黏土形态、极简主义、野兽派、新形态、便当网格、暗色模式等
- 95 种专业配色方案，涵盖 SaaS、电子商务、医疗健康、金融科技、美容美妆等行业
- 56 种字体组合，包含 Google Fonts 导入代码
- 24 种图表类型推荐，适用于仪表板和数据分析
- 10 个技术栈的最佳实践，支持 React、Next.js、Vue、Nuxt.js、Nuxt UI、Svelte、SwiftUI、React Native、Flutter、HTML+Tailwind
- 98 条用户体验指南，最佳实践、反模式与无障碍规则

**使用方式**

当你想要 `ui-ux` 工作时，该技能会自动激活。你只需要自然地在对话中提出设计需求：

```plaintext
我需要一个适合医疗健康应用的配色方案。
```

## 安装

将此插件添加到你的 Claude Code 配置中：

```bash
claude-code plugin install https://github.com/Fioooooooo/claude-plugins
```
