# Commit Commands 插件

使用简单的命令简化你的 git 工作流，包括提交、推送和创建拉取请求。

## 概览

Commit Commands 插件自动化常见的 git 操作，减少上下文切换和手动命令执行的次数。不再需要运行多个 git 命令，使用一个斜杠命令即可处理整个工作流。

## 命令

### `/commit`

创建一个 git 提交，并根据已暂存和未暂存的更改自动生成提交信息。

**它做了什么：**

1. 分析当前的 git 状态
2. 检查已暂存和未暂存的更改
3. 查看最近的提交信息以匹配你的仓库风格
4. 草拟合适的提交信息
5. 暂存相关文件
6. 创建提交

**用法：**

```bash
/commit
```

**示例工作流：**

```bash
# 修改你的代码
# 然后运行：
/commit

# Claude 将：
# - 检查你的更改
# - 暂存文件
# - 创建一个带有合适信息的提交
# - 展示提交状态
```

**功能：**

- 自动草拟与你的仓库风格匹配的提交信息
- 遵循约定的提交实践
- 避免提交包含秘密信息的文件（如 .env, credentials.json）
- 在提交信息中包含 Claude Code 属性

### `/clean-branch`

清理本地已经从远程仓库删除的分支。

**它做了什么：**

1. 列出所有本地分支以识别 [gone] 状态
2. 识别并删除与 [gone] 分支关联的工作树
3. 删除所有标记为 [gone] 的分支
4. 提供已清理分支的反馈

**用法：**

```bash
/clean-branch
```

**示例工作流：**

```bash
# 在 PR 合并和远程分支删除之后
/clean-branch

# Claude 将：
# - 寻找所有标记为 [gone] 的分支
# - 删除任何关联的工作树
# - 删除过时的本地分支
# - 报告清理了什么
```

**功能：**

- 处理常规分支和工作树分支
- 在删除分支前安全地删除工作树
- 清晰地报告删除了什么
- 如果不需要清理，则报告

**何时使用：**

- 合并和删除远程分支之后
- 当你的本地分支列表中充满了过时分支时
- 在常规仓库维护期间

## 安装

此插件包含在 Claude Code 仓库中。在使用 Claude Code 时，这些命令会自动可用。

## 最佳实践

### 使用 `/commit`

- 在提交之前检查已暂存的更改
- 让 Claude 分析你的更改并匹配你的仓库的提交风格
- 信任自动化的消息，但确保它是准确的
- 在开发期间用于常规提交

### 使用 `/clean-branch`

- 定期运行以保持分支列表整洁
- 特别在合并多个 PR 后很有用
- 安全运行 - 只删除远程已删除的分支
- 有助于维护整洁的本地仓库

## 工作流集成

### 快速提交工作流：

```bash
# 编写代码
/commit
# 继续开发
```

### 维护工作流：

```bash
# 多个 PR 合并之后
/clean-branch
# 清理工作空间以准备下一个特征
```

## 故障排除

### `/commit` 创建空提交

**问题**：没有更改可以提交

**解决方案**：

- 确保你有未暂存或已暂存的更改
- 运行 `git status` 确认更改存在

### `/clean-branch` 未找到分支

**问题**：没有标记为 [gone] 的分支

**解决方案**：

- 运行 `git fetch --prune` 更新远程跟踪
- 分支必须从远程删除才能显示为 [gone]

## 小贴士

- **与其他工具结合使用**：在开发期间使用 `/commit`
- **让 Claude 草拟消息**：提交信息分析会从你的仓库风格中学习
- **定期清理**：每周运行 `/clean-branch` 以保持分支列表整洁
- **推送前审核**：在推送之前总是审核提交信息和更改
